Follow these steps before uploading to GitHub. Docs should be updated so "scaladoc" button in GitHub shows the documents.

sbt clean
Remove-Item -Recurse -Force target\scala-3.9.0 -ErrorAction SilentlyContinue
sbt compile doc

Remove-Item -Recurse -Force docs -ErrorAction SilentlyContinue
Copy-Item -Recurse target\scala-{new version}\api docs
